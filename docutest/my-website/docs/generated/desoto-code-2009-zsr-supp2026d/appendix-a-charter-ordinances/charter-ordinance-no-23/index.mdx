A CHARTER ORDINANCE REPEALING SEVERAL CHARTER ORDINANCES THAT HAVE BEEN SUPERSEDED BY LATER ENACTMENTS OR ONLY APPLY TO CITIES OF THE THIRD CLASS

SECTION 1. Charter Ordinances 2, 3, 5, 10, 15, and 19 are hereby repealed.
